PROJECT 1 - HOW TO RUN (3 steps)
================================

STEP 1. One-time setup in MATLAB (R2024a or newer)
   Home > Add-Ons > Get Add-Ons, and make sure these are installed:
     - Communications Toolbox          - Deep Learning Toolbox
     - WLAN Toolbox                    - Computer Vision Toolbox
     - Bluetooth Toolbox               - Image Processing Toolbox
     - Signal Processing Toolbox       - DSP System Toolbox
     - "Deep Learning Toolbox Model for ResNet-18 Network"  (free add-on)
   Optional: Parallel Computing Toolbox (faster), a GPU (much faster),
             ADALM-PLUTO support package (only for the radio test).
   RUN_ME checks all of this for you and tells you exactly what is missing.

STEP 2. Unzip this folder, open it in MATLAB (make it the Current Folder),
        open RUN_ME.m and press the green Run button.
   - It does everything: downloads the MathWorks example network, generates
     the signals, builds the data set, trains, validates, tests.
   - With a GPU: full run (1500 frames, 20 epochs).
     Without a GPU: smaller run (600 frames, 10 epochs), several hours.
   - To only check that everything works first, set MODE = "quick"
     at the top of RUN_ME.m (about 15-30 minutes).
   - No ADALM-PLUTO connected? Fine: step 3.4 then shows a frame
     clearly marked SIMULATED, and everything else still runs.

STEP 3. When it finishes, send back this one file:
           Project1_results_to_send.zip
        It contains every figure, all numbers (results/RESULTS_SUMMARY.txt)
        and the full log. These are used to fill Chapter 8 of
        Project1_Report.docx.

IF SOMETHING GOES WRONG
   Send results/command_window_log.txt (or a screenshot of the red error).
